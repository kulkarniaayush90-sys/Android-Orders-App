# Ocean Orders UI

Android Native logistics order management UI built with Kotlin and XML.

## Overview

This project recreates a polished "My Orders" screen for an internship assignment. It focuses on UI quality, clean structure, and Material3 styling without using Compose or any cross-platform framework.

## Features

- RecyclerView with `DiffUtil`
- Material3 styling
- Responsive XML layouts
- Order filtering tabs
- Bottom navigation
- Reusable button and card components
- Ripple feedback for interactive elements

## Tech Stack

- Kotlin
- XML
- RecyclerView
- Material3
- ConstraintLayout
- ViewBinding

## Project Structure

- `app/src/main/java/com/oceanx/myorders/` - activity, adapter, and sample data
- `app/src/main/res/layout/` - screen and item XML layouts
- `app/src/main/res/drawable/` - custom drawables and vector icons
- `app/src/main/res/values/` - colors, strings, and themes

## Notes

- The app is UI-only, as requested in the assignment.
- Sample order data is used to demonstrate the screen state.
- All visuals are implemented in Android native Kotlin + XML.
